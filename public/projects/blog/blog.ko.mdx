## 프로젝트 소개

GitHub : [https://github.com/leey00nsu/leey00nsu-next-blog-v2](https://github.com/leey00nsu/leey00nsu-next-blog-v2)
Demo : [https://blog2.leey00nsu.com](https://blog2.leey00nsu.com)

Next.js 기반으로 직접 운영하는 기술 블로그입니다.

자체 Studio에서 작성한 원문을 AI로 번역해 한국어·영어 문서를 관리하고, GitHub API를 통해 브랜치에 직접 커밋해 작성·번역·커밋까지 이어지는 흐름을 자동화했습니다.

이후 콘텐츠가 늘어나면서 방문자가 원하는 정보를 직접 탐색하기 어려워지는 문제를 해결하기 위해 블로그 글, 소개, 프로젝트 문서를 근거로 답변하는 Q&A 챗봇을 추가했습니다.

## 주요 기능

- **콘텐츠 작성·게시 자동화**: Studio에서 MDX 작성, AI 번역, GitHub 커밋까지 연결
- **근거 기반 챗봇**: 블로그 글과 프로젝트 문서를 대상으로 Graph-RAG와 인용 URL 검증 적용
- **콘텐츠 플랫폼 기능**: 다국어 MDX, 이미지 업로드·최적화 및 포트폴리오 PDF 자동 생성

## 핵심 문제와 해결

### 다국어 콘텐츠 작성과 커밋의 반복 작업

한국어와 영어 문서를 별도로 작성하고 직접 커밋하면 번역 누락이나 문서 불일치가 발생하기 쉽습니다. Studio에서 작성한 콘텐츠를 OpenAI로 번역하고 GitHub API를 통해 브랜치에 직접 커밋하도록 연결해 작성·번역·커밋 흐름을 하나의 과정으로 자동화했습니다.

### 콘텐츠가 늘어날수록 어려워지는 정보 탐색

글과 프로젝트가 늘어나면 방문자가 필요한 맥락을 직접 찾아야 하는 부담도 커집니다. 이를 줄이기 위해 블로그 글과 소개, 프로젝트 문서를 검색해 답변하는 AI 기반 챗봇을 도입했습니다. Lexical·Curated 검색과 PostgreSQL(pgvector) 기반 Graph-RAG를 결합하고, 질문 라우터가 질문 유형에 따라 검색 경로를 결정하도록 구성했습니다. 답변에 사용한 인용 URL이 검색 결과에 포함되는지 검증하고, 검증된 출처가 없는 생성 답변은 제공하지 않도록 했습니다.

### 이미지로 인한 렌더링 성능 저하

이미지의 크기와 Placeholder 정보를 알 수 없는 상태로 렌더링하면 레이아웃 이동과 초기 이미지 로딩 성능 문제가 발생할 수 있습니다. 업로드된 이미지의 width·height·LQIP 메타데이터를 사전에 생성하고 이를 렌더링에 활용하도록 구성했습니다.
