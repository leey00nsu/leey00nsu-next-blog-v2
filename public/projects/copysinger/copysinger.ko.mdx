## 프로젝트 소개

GitHub : [https://github.com/leey00nsu/copy-singer](https://github.com/leey00nsu/copy-singer)
Demo : [https://copysinger.leey00nsu.com/](https://copysinger.leey00nsu.com/)

평소 TTS와 Voice Cloning 기술에 관심이 많아 이를 활용한 서비스를 직접 만들어 보고 싶었습니다.

기존에 검토했던 방식은 사용자마다 별도의 모델을 학습해야 해 GPU 비용과 준비 시간이 필요했지만, 사전 학습된 SoulX-Singer를 활용해 사용자별 추가 학습 없이 짧은 레퍼런스 음성으로 노래 목소리를 변환하는 기능을 제품 형태로 구현했습니다.

단순한 음성 변환에 그치지 않고, 사용자의 목소리를 분석해 잘 맞는 노래와 키를 추천하고 선택한 곡의 AI 믹싱까지 이어지는 서비스로 확장했습니다.

## 주요 기능

- **목소리 분석**: 녹음 음성에서 관측 음역, 주요 음역, 중심음과 피치 흐름 분석
- **노래·키 추천**: 보컬 프로필과 곡별 음역을 비교해 적합도, 추천 키와 추천 이유 제공
- **AI 믹싱**: 선택한 곡의 보컬을 분리하고 사용자 목소리로 변환해 반주와 재결합

## 핵심 문제와 해결

### 사용자별 Voice Cloning 학습 비용

기존에 검토했던 방식은 사용자마다 별도의 모델 가중치를 학습해야 해 GPU 비용과 준비 시간이 필요했습니다. 사전 학습된 SoulX-Singer의 Zero-shot 방식을 적용해 사용자별 추가 학습 없이 짧은 레퍼런스 음성만으로 AI 보컬을 생성하도록 구성했습니다.

### 단순 음역 비교로는 부족한 노래·키 추천

최저·최고음만으로는 실제 곡의 적합도와 필요한 키 조정을 판단하기 어렵습니다. librosa/pYIN으로 보컬 프로필을 추출하고, 음역 겹침·고저음 부담·키 이동 비용을 계산해 추천 점수와 추천 키, 추천 이유를 함께 제공하도록 설계했습니다.

### 긴 AI 작업의 안정적인 처리

분석·보컬 분리·AI 믹싱처럼 처리 시간이 긴 작업을 웹 요청 안에서 수행하면 화면 이탈이나 서버 재시작 시 작업이 유실될 수 있습니다. Modal CPU/GPU와 PostgreSQL 작업 큐를 이용해 작업을 백그라운드에서 처리하고, 이후 다시 상태와 결과를 조회할 수 있도록 구성했습니다.
