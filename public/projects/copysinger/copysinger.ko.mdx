## 프로젝트 소개

GitHub : [https://github.com/leey00nsu/copy-singer](https://github.com/leey00nsu/copy-singer)
Demo : [https://copysinger.leey00nsu.com/](https://copysinger.leey00nsu.com/)

평소 TTS와 voice cloning 기술에 관심이 많아 이를 활용한 서비스를 직접 만들어 보고 싶었습니다. 하지만 기존에 검토한 방식은 사용자 목소리마다 `.pth` 모델 가중치를 만들기 위한 별도 학습이 필요했고, GPU 비용과 준비 시간이 큰 진입 장벽이 되었습니다.

그러던 중 별도의 사용자별 학습 없이 짧은 레퍼런스 음성만으로 노래 목소리를 변환하는 zero-shot 오픈소스 `SoulX-Singer`를 접했습니다. 이를 활용하면 모델을 매번 학습하지 않고도 voice cloning 경험을 제품으로 구현할 수 있다고 판단해 `Copysinger`를 만들게 되었습니다.

단순한 음성 변환 데모에 그치지 않고, 한 소절을 분석해 내 목소리에 잘 맞는 노래와 키를 추천하고 선택한 곡의 AI 믹싱까지 이어지는 서비스로 확장했습니다.

## 핵심 기능

- 목소리 분석: 브라우저 녹음 또는 오디오 파일에서 관측 음역, 주요 음역, 중심음과 피치 흐름 분석
- 노래·키 추천: 보컬 프로필과 곡별 음역·원키를 비교해 적합도, 추천 키와 추천 이유 제공
- AI 믹싱: 선택한 곡만 보컬 분리, 자동 피치 이동과 반주 재결합 수행
- 라이브러리: 보컬 프로필과 분석 레퍼런스, 믹싱 결과 및 처리 이력 관리
- 관리자 도구: 추천곡과 원곡 음원, 분석 상태, 공개 여부를 운영하고 카탈로그 스냅샷 관리

## Problem

- **Voice cloning의 높은 진입 비용**: 사용자별 모델 학습이 필요한 방식은 GPU 비용과 준비 시간이 커 서비스로 확장하기 어려움
- **선곡 기준의 모호함**: 최저·최고음만으로는 어떤 곡이 잘 맞고 키를 얼마나 조정해야 하는지 판단하기 어려움
- **추천 근거 부족**: 단순 음역 겹침만 사용하면 녹음 품질과 실제 곡 적합도가 섞여 추천 순위를 신뢰하기 어려움
- **분석과 합성의 목적 차이**: 자연스러운 음역 분포를 보는 분석과 깨끗한 AI 믹싱에는 서로 다른 음성 구간이 필요
- **긴 오디오 작업의 안정성**: 분석과 믹싱을 웹 요청 안에서 처리하면 화면 이탈이나 서버 재시작 시 작업이 유실될 수 있음

## Solution

- 별도의 사용자별 사전 학습이 필요 없는 zero-shot 기반 `SoulX-Singer`로 짧은 레퍼런스 음성만 사용해 노래 목소리 변환
- `librosa`/pYIN으로 관측 음역, 주요 음역, 중심음과 피치 흐름을 분석해 보컬 프로필 생성
- 음역 겹침, 고·저음 부담과 키 이동 비용을 함께 계산해 전체 곡의 추천 점수·추천 키·이유 제공
- 분석용 원본과 합성용 레퍼런스를 분리하고, AI 믹싱에는 품질이 좋은 중음 구간만 선별해 사용
- Modal CPU/GPU와 PostgreSQL 영속 큐를 이용해 분석·보컬 분리·AI 믹싱을 백그라운드에서 처리
- Google OAuth로 사용자 데이터를 분리하고 Leemage 미디어 저장, 티켓 원장과 관리자 카탈로그 도구 구성

## Impact

- **학습 과정 제거**: 사용자별 `.pth` 모델 가중치를 별도로 학습하지 않고 레퍼런스 음성만으로 AI 믹싱 생성
- **선곡 흐름 연결**: 목소리 분석부터 전체 곡 비교, 추천 키와 선택형 AI 믹싱까지 하나의 흐름으로 제공
- **추천 신뢰도 향상**: 음역 적합도와 키 조정 이유를 함께 보여주고 같은 입력에 동일한 결과를 제공
- **운영 안정성 확보**: 재접속 가능한 작업 큐, 사용자별 라이브러리와 관리자 도구로 서비스 운영 기반 마련
