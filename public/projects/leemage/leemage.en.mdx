## Project Overview

GitHub : [https://github.com/leey00nsu/leemage](https://github.com/leey00nsu/leemage)
Demo : [https://leemage.leey00nsu.com/](https://leemage.leey00nsu.com/)

Storage costs became a concern when adding file uploads to side projects, so I built a self-hosted file management platform using the free tiers of OCI Object Storage and Cloudflare R2.

The platform organizes images, videos, documents, and other files by project, with a REST API and TypeScript SDK so other projects can use the same upload capabilities.

I also designed a common interface to avoid coupling the service to a particular storage provider and expanded it to include image transformation and optimization.

## Key Features

- **File management**: Uploads and manages images, videos, documents, and other files by project
- **Image processing**: Resizes images and converts them to formats such as WebP and AVIF
- **External integration**: Supports a REST API, TypeScript SDK, OCI Object Storage, and Cloudflare R2

## Key Challenges and Solutions

### Server load from large file uploads

Relaying files through the application server increases memory and network load with file size. I used presigned URLs to send the initial upload body directly from the client to Object Storage, while the server handles upload verification and file registration. When image validation and transformation are needed, the server reads and processes the original.

### Different APIs across storage providers

OCI Object Storage and Cloudflare R2 use different APIs, so changing storage providers can require changes to service code. I separated service logic from provider implementations using a common storage interface and adapters, allowing OCI or R2 to be selected within the same file management flow.

### Image size and transformation costs

Storing and transferring original images as-is can result in large files and higher network costs. I used Sharp to generate requested image sizes, formats, and thumbnails sequentially, and manage the URLs, sizes, and formats of both originals and variants together.
