## Project Overview

GitHub : [https://github.com/leey00nsu/leesfield](https://github.com/leey00nsu/leesfield)
Demo : [https://leesfield.leey00nsu.com/](https://leesfield.leey00nsu.com/)

While adding AI image and video generation to side projects, I wanted to build my own generation platform that could run multiple models through one interface.

I used Hugging Face Zero GPU to limit initial costs and built a flow for selecting and running image, video, and audio models, then reusing the results with their prompts and settings.

I also managed model settings in a catalog and separated provider-specific calling conventions to support adding more models and providers over time.

## Key Features

- **Multimodal AI generation**: Select and run image, video, and audio models through one interface
- **Spaces**: Connect input, generation, editing, and output nodes into AI generation workflows
- **Model operations**: Manage a database-backed model catalog, generation history, and request monitoring

## Key Challenges and Solutions

### Different API interfaces across models

AI models differ in input parameters, calling conventions, and timeouts, which can complicate service code as more models are added. I separated provider-specific calls into adapters so service logic and provider implementations could be maintained separately.

### Code changes for every new model

Defining model parameters and UI settings directly in code requires application changes whenever a model is added. I stored input schemas, defaults, and UI types in a database catalog and rendered the interface dynamically from that data, allowing models to be added without code changes within supported providers and input contracts.

### Understanding generation request activity

Long-running AI generation requests make it difficult to see the overall state when failures or delays occur. I built a monitoring dashboard with active request counts, pending and processing states, error rates, and average/P95 request processing times, along with request activity by model and API key and daily trends.
