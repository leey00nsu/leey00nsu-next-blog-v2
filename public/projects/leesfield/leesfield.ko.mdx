## 프로젝트 소개

GitHub : [https://github.com/leey00nsu/leesfield](https://github.com/leey00nsu/leesfield)
Demo : [https://leesfield.leey00nsu.com/](https://leesfield.leey00nsu.com/)

사이드 프로젝트에 AI 이미지·비디오 생성 기능을 추가하면서, 여러 생성 모델을 하나의 인터페이스에서 사용할 수 있는 자체 생성 플랫폼을 구축하고 싶었습니다.

초기 비용 부담을 낮추기 위해 Hugging Face Zero GPU를 활용하고, 이미지·비디오·오디오 모델을 선택해 실행한 뒤 생성 결과와 프롬프트·설정을 다시 활용할 수 있도록 구성했습니다.

또한 모델별 설정을 카탈로그로 관리하고, 프로바이더별 호출 방식을 분리해 새로운 모델과 프로바이더를 지속적으로 추가할 수 있는 구조를 만들었습니다.

## 주요 기능

- **멀티모달 AI 생성**: 이미지·비디오·오디오 모델을 하나의 인터페이스에서 선택하고 실행
- **Spaces**: 입력·생성·편집·출력 노드를 연결해 AI 생성 워크플로우 구성
- **모델 운영**: DB 기반 모델 카탈로그, 생성 히스토리 및 요청 모니터링 제공

## 핵심 문제와 해결

### 모델마다 다른 API 인터페이스

AI 모델마다 입력 파라미터와 호출 방식, 타임아웃이 달라 모델이 늘어날수록 서비스 코드가 복잡해질 수 있습니다. 프로바이더별 호출 로직을 어댑터로 분리해 서비스 로직과 프로바이더별 구현을 나누어 관리하도록 구성했습니다.

### 모델 추가마다 필요한 코드 변경

모델별 파라미터와 UI 설정을 코드에 직접 정의하면 새로운 모델을 추가할 때마다 애플리케이션 수정이 필요합니다. 모델의 입력 스키마와 기본값, UI 타입 등을 DB 카탈로그에서 관리하고 이를 기반으로 화면을 동적으로 렌더링해, 지원하는 프로바이더와 입력 규격 안에서는 코드 수정 없이 모델을 추가할 수 있도록 했습니다.

### AI 생성 요청의 운영 상태 파악

처리 시간이 긴 AI 생성 요청은 실패나 지연이 발생해도 전체 상태를 파악하기 어렵습니다. 진행 중인 요청 수와 pending·processing 상태, 에러율, 평균·P95 요청 처리 시간을 확인할 수 있는 통합 모니터링 대시보드를 구성하고, 모델별·API 키별 요청 현황과 일별 추이를 조회할 수 있도록 했습니다.
