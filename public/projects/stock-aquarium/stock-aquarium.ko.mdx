## 프로젝트 소개

GitHub : [https://github.com/leey00nsu/stock-aquarium](https://github.com/leey00nsu/stock-aquarium)<br />
Demo : [https://aquarium.leey00nsu.com/](https://aquarium.leey00nsu.com/)

한국투자증권(KIS)의 실시간 주식 체결 데이터를 **3D 수조 속 물고기 움직임으로 변환한 데이터 시각화 서비스**입니다. 매수 체결은 오른쪽으로 이동하는 빨간 물고기, 매도 체결은 왼쪽으로 이동하는 파란 물고기로 표현하고 체결량에 따라 크기를 조절합니다.

숫자와 차트 중심의 시세 화면 대신 시장의 방향, 체결 강도, 거래량과 변동성을 하나의 수중 환경으로 보여주는 것이 목적입니다. 거래량이 늘면 물고기와 입자가 빨라지고, 변동성이 커지면 수조에 폭풍과 카메라 흔들림이 발생합니다.

## 핵심 기능

- **체결 시각화**: 집계된 체결 방향과 상대적 규모를 물고기의 색상·이동 방향·크기로 표현합니다(미국 종목의 방향은 호가·직전가 기반 추정).
- **시장 변화 표현**: 거래량과 가격 변동에 따라 물고기 속도와 수조의 폭풍 효과를 바꿉니다.
- **실시간 종목 조회**: 국내·미국 종목을 검색하고 KIS 실시간 데이터를 공유 연결로 수신합니다.

## Problem

- **체결 시각화**: 절대 체결량만으로 크기를 정하면 유동성이 다른 종목의 거래 변화를 표현하기 어려웠습니다.
- **연결 공유**: 브라우저마다 KIS 연결과 같은 종목의 데이터 처리를 반복하면 구독 자원이 중복됩니다.
- **렌더링 자원 관리**: 체결마다 물고기 모델과 애니메이션을 만들면 유입량에 따라 3D 객체 수가 늘어납니다.

## Solution

- **체결 시각화**: 종목별 최근 수신 데이터의 체결량 백분위로 물고기 크기를 정하고, 거래량과 가격 변동을 이동 속도·폭풍 효과에 연결했습니다.
- **연결 공유**: 서버 프로세스의 KIS 연결을 공유하고 종목별로 체결을 집계·직렬화한 뒤 같은 SSE 데이터를 구독 브라우저에 배포했습니다.
- **렌더링 자원 관리**: 80개 물고기 풀을 재사용하고, 생성 한도를 넘는 이벤트는 방향별로 합산해 빈 슬롯이 생기면 반영했습니다.

## Impact

- **체결 시각화**: 종목 내부의 상대적인 체결 규모와 최근 가격 변화를 한 수조에서 볼 수 있게 했습니다.
- **연결 공유**: 같은 서버 프로세스에서 동일 종목을 보는 사용자가 종목 구독과 직렬화 결과를 공유하도록 구성했습니다.
- **렌더링 자원 관리**: 표시할 물고기 수에 상한을 두면서 처리 대기 중인 방향별 체결량을 다음 물고기에 합쳐 표현했습니다.
